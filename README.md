# בוט טלגרם להחלפת פנים בתמונות ובסרטונים, ב-Python, שרץ בטלפון (Termux)

## שלב 1 – יצירת בוט בטלגרם
1. בטלגרם, פתח צ'אט עם **@BotFather**
2. שלח `/newbot`, תן שם ושם משתמש (חייב להסתיים ב-`bot`)
3. תקבל **טוקן** – שמור אותו ואל תשתף אותו עם אף אחד

## שלב 2 – התקנת Termux
התקן את Termux מ-**F-Droid** (הגרסה ב-Google Play ישנה ולא עובדת טוב).

## שלב 3 – התקנה ב-Termux
```bash
pkg update && pkg upgrade -y
pkg install python git python-numpy python-onnxruntime python-scipy python-pillow ffmpeg -y
git clone https://github.com/benny054727/HTML.git bot
cd bot
pip install -r requirements.txt
python download_models.py
```

`download_models.py` מוריד כ-2.3GB של מודלים לתיקייה `models/` ובודק שהם תקינים.

## שלב 4 – הגדרת הטוקן
```bash
cp .env.example .env
nano .env
```
החלף את הטוקן לדוגמה בטוקן שקיבלת. שמירה: `Ctrl+O` ואז `Enter`, יציאה: `Ctrl+X`.

## שלב 5 – הרצה
```bash
./run.sh
```
`run.sh` מפעיל את הבוט מחדש אוטומטית אם הוא נופל. Ctrl+C עוצר הכל.

### הרצה ברקע (בלי חלון)
```bash
./run.sh --background   # מפעיל ברקע
tail -f bot.log         # לראות מה קורה (Ctrl+C רק סוגר את התצוגה)
./stop.sh               # עוצר את הבוט
```

### הפעלה אוטומטית כשהטלפון נדלק
1. התקן את **Termux:Boot** מ-F-Droid, ופתח אותו פעם אחת.
2. הרץ פעם אחת:
```bash
./install_boot.sh
```
לביטול: `rm ~/.termux/boot/start-bot.sh`

### כדי שהבוט ימשיך לרוץ
- בהגדרות אנדרואיד: בטל **אופטימיזציית סוללה** ל-Termux (ללא הגבלה).
- `run.sh` מונע מהטלפון להרדים את Termux (wake lock).
- הבוט רץ רק כשהטלפון דלוק ומחובר לאינטרנט.

## פקודות הבוט
| פקודה | מה עושה |
|---|---|
| `/start` | הודעת פתיחה |
| `/help` | רשימת פקודות |
| `/time` | השעה עכשיו |
| `/id` | ה-ID שלך |
| `/swap` | החלפת פנים: תמונה מקורית ואז תמונת יעד |
| `/swapvideo` | החלפת פנים בסרטון: תמונה מקורית ואז סרטון (עד 20MB, נחתך ל-15 שניות) |
| `/videomode fast` | מצב סרטונים: `fast` (ברירת מחדל, 10 פריימים לשנייה) / `quality` (איטי מאוד) |
| `/glasses always` | איכות ההחלפה: `always` (ברירת מחדל - איכות מלאה) / `auto` (מהיר בערך פי 2, דמיון קצת פחות מדויק) |
| `/cancel` | ביטול החלפה באמצע |
| `/enhance gpen` | בחירת מודל חידוד: `gpen` (חזק, ברירת מחדל) / `restore` (טבעי) / `gfpgan` (עדין) / `off` |
| `/color 60` | כמה מצבע העור של התמונה המקורית להעביר (0-100, ברירת מחדל 60) |
| טקסט רגיל | הבוט מחזיר אותו |

## החלפת פנים
1. שולחים `/swap`
2. שולחים **תמונה מקורית** - ממנה נלקחות הפנים (הפנים הגדולות בתמונה)
3. שולחים **תמונת יעד** - הפנים הגדולות בה מוחלפות

## החלפת פנים בסרטון
1. שולחים `/swapvideo`
2. שולחים **תמונה מקורית**
3. שולחים **סרטון** (עד 20MB - מגבלה של טלגרם לבוטים). סרטון ארוך מ-15 שניות נחתך.

הבוט שולח עדכוני התקדמות ומחזיר את הסרטון עם הסאונד המקורי.
סרטון לוקח זמן: כל פריים עובר את כל שלבי ההחלפה. במצב `fast` (15 פריימים לשנייה, 720p, בלי חידוד)
סרטון של 15 שניות הוא 225 פריימים.

⚠️ השתמש רק בתמונות וסרטונים של אנשים שהסכימו לכך.

ההחלפה נעשית בשני שלבים: inswapper (מוחק משקפיים ודברים שמכסים את הפנים) ואז HyperSwap (איכות ודמיון). אחרי ההחלפה הפנים עוברות חידוד - GPEN כברירת מחדל (אפשר להחליף או לכבות עם `/enhance`).

המודלים (InsightFace: SCRFD, ArcFace, inswapper_128; FaceFusion: HyperSwap 1a; GPEN, RestoreFormer++, GFPGAN) מותרים לשימוש אישי ולא מסחרי בלבד (HyperSwap: רישיון ResearchRAIL).
